# 飞牛 fnOS 桌面客户端 开发文档 v0.1

> 状态：开发依据 ｜ 上游：需求分析-v0.1.md（已确认）｜ 技术栈：Tauri 2 + Rust + Vue3 + WebView2
> 本文档定义：技术栈明细、目录结构、数据模型、关键实现方案、CI 与发布、里程碑任务分解、待真机验证项

## 1. 技术栈明细

| 层 | 选型 | 版本策略 |
|---|---|---|
| 壳框架 | **Tauri 2** | 锁定 Cargo.lock |
| 后端语言 | Rust（edition 2021） | stable，CI 用 rust-stable |
| 前端壳 | Vue3 + Vite + TypeScript | 锁定 package-lock.json |
| UI | 纯 CSS（深色玻璃质感，backdrop-filter），**不引 UI 框架** | 减少依赖面（安全诉求） |
| 构建 | tauri-cli + tauri-action（CI） | 本地不装工具链 |

### 关键 Rust crate / 插件

| crate | 用途 |
|---|---|
| tauri（2.x） | 主框架 |
| tauri-plugin-global-shortcut | 全局快捷键（锁定/隐藏） |
| tauri-plugin-single-instance | 单实例（二次启动聚焦已有窗口） |
| tauri-plugin-store | 配置持久化（JSON） |
| tauri-plugin-updater | 自动更新（GitHub Releases 源） |
| tauri-plugin-window-state | 窗口位置/大小记忆 |
| argon2 | 启动密码哈希（PHC 格式） |
| serde / serde_json / uuid / chrono | 数据模型与序列化 |

> 明确不引入：任何第三方 NAS 闭源 SDK；任何网络通信库（连接全走 WebView2 自身 + fnOS 网页，Rust 侧零网络逻辑——缩小攻击面）。

## 3. 数据模型

### 3.1 ServerProfile（每台 NAS）

```rust
struct ServerProfile {
  id: String,          // uuid v4
  name: String,        // 显示名（默认取地址）
  url: String,         // 完整地址，如 https://192.168.1.16:5667 或 https://aipoly.iepose.cn
  trust_cert: bool,    // 是否信任该 NAS 自签证书（v1 占位，见 §4.7 待验证）
  data_dir: String,    // WebView2 数据分区目录名 = profile id
  zoom: f64,           // 该 Profile 的缩放倍数（默认 1.0）
  created_at: i64,
  last_used_at: i64,
}
```

### 3.2 AppSettings

```rust
struct AppSettings {
  lock_password_hash: Option<String>, // argon2 PHC 字符串；None=未设置
  shortcuts: Shortcuts,               // { lock: "Ctrl+Alt+L", hide: "Ctrl+Alt+H" }
  theme: Theme,                       // system | light | dark（默认 system）
}
```

### 3.3 存储布局（%APPDATA%/com.fnos.desktop/）

```
config.json          # AppSettings（tauri-plugin-store）
profiles.json        # ServerProfile 列表
webviews/
  └── <profile_id>/  # 每台 NAS 的 WebView2 数据分区（登录态在此，客户端不解析）
```

> 安全要点：profiles.json 只存地址/显示名，**不含任何凭据**；NAS 账号密码只存在于网页登录框 → WebView 分区内；忘密重置 = 删 lock_password_hash + 清空 webviews/ 目录。

## 4. 关键实现方案

### 4.1 主窗口与 NAS 窗口

- **主窗口**：加载本地壳 UI（ServerList / Settings / LockScreen），Tauri 原生窗口
- **NAS 窗口**：`WebviewWindowBuilder::new(app, label, WebviewUrl::External(profile.url))` + `.data_directory(app_data_dir/webviews/<profile_id>)` —— 独立数据分区，登录态天然隔离
- 每个 NAS 窗口标签 `nas_<profile_id>`；同一 Profile 已有窗口则聚焦，不重复开
- 窗口关闭 → 隐藏到托盘（拦截 `CloseRequested`，仅"退出"菜单真正退出）

### 4.2 多窗口多任务（fnOS 内应用独立窗口）

- fnOS 网页内部 `target=_blank` / `window.open` 默认行为不可控，**方案**：注入脚本改写 `window.open`，URL 属于当前 Profile 域名 → `invoke('open_app_window', { url })` → 后端开新 WebView 窗口（复用同一分区），并拦截新窗口导航禁止跳外域
- 外链（非当前域名）→ 交给系统默认浏览器打开（保持壳内纯净）
- **待真机验证**：fnOS SPA 的 window.open 行为是否可完整接管（见 §10）

### 4.3 启动密码与锁屏

- **设置密码**：argon2（`argon2` crate，默认参数，输出 PHC 串）→ 存 config.json
- **启动流程**：启动 → 若已设密码 → 先显示 LockScreen（本地 UI）→ 校验通过 → ServerList；校验失败不渲染任何 NAS 内容
- **一键锁定**：托盘菜单/全局快捷键 → 打开 LockScreen 覆盖 + 隐藏主窗口与 NAS 窗口（`window.hide()`）；解锁后恢复
- **忘密重置**：LockScreen 提供"忘记密码"→ 二次确认 → 删哈希 + 清空 `webviews/` 全部分区 → 回到 ServerList（需重新登录各 NAS）

### 4.4 全局快捷键

- `tauri-plugin-global-shortcut` 注册锁定/隐藏，默认 `Ctrl+Alt+L` / `Ctrl+Alt+H`，Settings 可改，改后热重注册
- 快捷键在**任意应用前台**均生效（全局）

### 4.5 系统托盘

- 托盘图标 + 菜单：显示主界面 / 锁定 / 退出
- 单实例：`tauri-plugin-single-instance`，二次启动聚焦已有窗口

### 4.6 视图缩放

- 主窗口菜单 + 快捷键（Ctrl+= / Ctrl+- / Ctrl+0）调 `webview.zoom()`，按 Profile 记忆缩放倍数（写回 profiles.json）

### 4.7 自签证书（风险项，需真机验证）

- WebView2 默认拦截自签证书。两条路，先验证 A：
  - **方案 A（首选）**：引导用户首次连接前用系统浏览器访问 `https://<ip>:5667` 并信任证书 → 证书进 Windows 证书存储 → WebView2 复用系统信任（一次信任全客户端生效）。零代码。
  - **方案 B（备选）**：Tauri 证书错误事件 API（`on_certificate_error`，需 2.x 较新版本）→ Profile 级 `trust_cert` 确认。
- M2 阶段真机验证后定稿（见 §10）

### 4.8 自动更新

- `tauri-plugin-updater`，更新源 = GitHub Releases（tauri-action 自动生成 `latest.json`）
- **签名链路**：`tauri signer generate` 生成密钥对 → 公钥写 `tauri.conf.json` → 私钥 base64 + 密码存 GitHub Actions secrets（`TAURI_SIGNING_PRIVATE_KEY` / `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`），**绝不入库**
- 壳 UI"关于"页提供手动检查更新 + 启动时静默检查

## 5. 前端壳页面规格

| 页面 | 元素 | 说明 |
|---|---|---|
| ServerList | 服务器卡片（名称/地址/上次使用）、打开、编辑、删除、添加 | 卡片空态引导"添加第一台 NAS" |
| ServerForm | 名称、地址（IP:端口 / 域名，支持粘贴）、信任证书开关（占位） | 保存后回列表 |
| Settings | 启动密码（设置/修改/关闭）、快捷键配置、主题（跟随系统/浅/深）、关于（版本/检查更新） | 密码修改需验证旧密码 |
| LockScreen | 密码输入、忘记密码入口 | 深色玻璃质感，无任何 NAS 内容 |

**深色玻璃主题**：CSS tokens（`--bg-glass: rgba(20,24,32,.72)` + `backdrop-filter: blur(18px)`），跟随 `prefers-color-scheme`。

## 7. CI 与发布

### 7.1 release.yml 概要
```
on: push tags v*
jobs:
  build (windows-latest)
    - checkout
    - setup node 20 + rust stable + pnpm
    - tauri-action（编译 + 签名 + 打包）
    - 产物：fnos-desktop_<ver>_x64-setup.exe（NSIS）
    -        + fnos-desktop_<ver>_x64_portable.exe（NSIS portable 模式）
    - 发布 GitHub Release（含 latest.json，供 updater）
```

### 7.2 前置准备（M4 阶段执行）
- 生成更新密钥对：`tauri signer generate -w fnos-desktop.key`
- Actions secrets 配置：`TAURI_SIGNING_PRIVATE_KEY`、`TAURI_SIGNING_PRIVATE_KEY_PASSWORD`
- 发布时需用户提供一次 **GitHub PAT**（可仅授权该仓库）

## 9. 开发约束

1. **代码由 Hermes 分批交付**（每里程碑一轮），老大在 Win11 真机验证后进入下一轮
2. 依赖全部锁定（Cargo.lock / package-lock.json），变更走明示
3. 不引入任何第三方 NAS 闭源 SDK；Rust 侧零网络逻辑
4. 权限最小化：capabilities/default.json 只声明用到的能力
5. 重大交付前按用户偏好开子代理独立复审
